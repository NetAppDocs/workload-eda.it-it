= Utilizzare la dashboard Panoramica nei carichi di lavoro EDA
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
In qualità di amministratore IT che gestisce carichi di lavoro EDA su più file system FSx for ONTAP (cluster ONTAP), puoi utilizzare la dashboard Panoramica per valutare rapidamente lo stato e l'utilizzo del cluster. Usala per decidere dove posizionare nuovi volumi o job, identificare i candidati per lo spostamento di volumi o SVM e determinare quando scalare la capacità o il throughput.



== Panoramica

La dashboard Panoramica offre una visione centralizzata dei cluster FSx for ONTAP, inclusi capacità e throughput. Utilizzala per aggiungere nuovi volumi, ribilanciare i carichi di lavoro e pianificare la capacità o il throughput.

Il dashboard include:

* *Stato di salute del cluster*: Informazioni riepilogate nella parte superiore del dashboard che evidenziano gli eventi di latenza, l'utilizzo delle unità SSD e i consigli sulla capacità, e gli eventi ONTAP EMS sui file system.
* *Tabella dei cluster*: una tabella dettagliata e ricercabile che mostra l'utilizzo e le metriche di performance per ciascun cluster, con supporto per filtri, ordinamento, impaginazione ed esportazione in formato CSV.




== Requisiti

Prima di utilizzare la dashboard, assicurati di soddisfare i seguenti requisiti:

Credenziali AWS con autorizzazioni di visualizzazione:: È necessario configurare le credenziali AWS in Workload Factory con almeno le autorizzazioni di lettura (visualizzazione) per General Storage. Le credenziali _Basic_ non sono supportate.
+
--
Se non hai configurato le credenziali con autorizzazioni di visualizzazione, verrai reindirizzato alla pagina di configurazione delle credenziali AWS quando apri la scheda Panoramica.

Se non hai configurato le credenziali AWS, consulta link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["Aggiungi credenziali AWS"^].

--
Attiva la dashboard:: Dopo che Workload Factory avrà confermato le credenziali con i permessi di visualizzazione, sarà necessario attivare la dashboard per iniziare a raccogliere le metriche CloudWatch per i file system FSx for ONTAP.



NOTE: La raccolta delle metriche potrebbe richiedere del tempo dopo aver fornito il consenso. La dashboard ti avvisa mentre la raccolta iniziale è in corso.

.Passi
. Accedi utilizzando uno dei link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["esperienze di console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger"] e poi seleziona *EDA*.
. Seleziona la scheda *Overview*.
. Se non vengono rilevate credenziali con autorizzazioni di visualizzazione, seleziona *Aggiungi credenziali* e segui le istruzioni per configurare le credenziali AWS con autorizzazioni di visualizzazione. Quindi torna alla scheda *Overview*.
. Esaminare la richiesta di consenso che descrive le metriche CloudWatch che verranno raccolte per i file system FSx for ONTAP.
. Selezionare *Attiva* per attivare la dashboard e iniziare la raccolta delle metriche.


.Risultato
Workload Factory inizia a raccogliere le metriche CloudWatch per tutti i file system FSx for ONTAP associati alle credenziali AWS configurate. La dashboard si popola man mano che le metriche diventano disponibili. Viene visualizzata una notifica se la raccolta è ancora in corso.



== Filtra la dashboard

Utilizza i filtri nella parte superiore del dashboard per concentrarti su specifici file system. Questi filtri si applicano alle sezioni relative a latenza, utilizzo ed eventi ONTAP, nonché alla tabella dei cluster.

Filtri disponibili:

* *Regione*: Filtra per una o più regioni AWS.
* *Account AWS*: Filtra in base a uno o più account AWS associati alle credenziali configurate.


Quando aggiorni le selezioni del filtro, tutte le informazioni vengono aggiornate per mostrare solo i file system corrispondenti.



== Stato di salute del cluster

Nella parte superiore del pannello di controllo viene visualizzata una panoramica dello stato di salute e dell'attività dei file system filtrati. Queste informazioni vengono mostrate solo se almeno un collegamento FSx for ONTAP è associato ai file system. Se non sono presenti collegamenti, le informazioni vengono nascoste.

* *Latenza*: visualizza il numero di eventi di latenza rilevati nei file system considerati.
* *Utilizzo*: Visualizza lo stato di utilizzo dell'SSD e identifica i file system con raccomandazioni di capacità attiva.
* *Eventi ONTAP*: Visualizza il numero di eventi EMS rilevati, categorizzati per Capacità, Disponibilità e protezione, e Sicurezza e altro.




=== Latenza

Visualizza il numero di eventi di latenza rilevati nei file system considerati.

* Quando si seleziona *Review*, viene visualizzata la scheda *Latenza*.
* È possibile visualizzare le informazioni sulla latenza solo se è stato abilitato il monitoraggio della latenza. Se non sono state configurate soglie di latenza, selezionare *Configura*. Per dettagli sul monitoraggio della latenza, vedere link:task-monitor-latency.html["Analisi della latenza FSx"^].




=== Utilizzo

Visualizza il numero di file system inclusi nell'ambito che presentano almeno un cluster con utilizzo SSD superiore all'80% e il numero di file system con raccomandazioni di capacità attive. Questo consente di identificare rapidamente i file system che potrebbero richiedere attenzione alla capacità.



==== Raccomandazioni sulla capacità

Workload Factory esegue automaticamente un algoritmo di raccomandazione della capacità per ogni file system FSx for ONTAP visibile nell'inventario EDA. L'algoritmo esegue una scansione ogni 24 ore e identifica quando è consigliabile regolare la capacità degli SSD.

Quando viene individuata una raccomandazione:

* Ricevi una notifica immediata (email o WAD), in base alle impostazioni di notifica di Workload Factory. Le notifiche vengono inviate non appena viene identificata una raccomandazione, invece di attendere il riepilogo settimanale.
* Nella riga della tabella Clusters viene visualizzata un'icona a forma di lampadina per ogni file system con una raccomandazione attiva.
* Viene visualizzato il numero totale di file system con raccomandazioni attive. Ciò garantisce che le raccomandazioni siano visibili anche se il file system interessato non si trova nella prima pagina della tabella.




==== Visualizza e applica le raccomandazioni sulla capacità

.Passi
. Accedi utilizzando uno dei link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["esperienze di console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger"] e poi seleziona *EDA*.
. Seleziona la scheda *Overview*.
. Nella tabella *Clusters*, individua un file system con un indicatore a forma di lampadina.
+
Passa il mouse sopra l'indicatore a forma di lampadina per visualizzare una descrizione a comparsa con una breve spiegazione del suggerimento.

. Seleziona il nome del cluster nella tabella per aprirlo e visualizzare i suggerimenti.
. Esaminate le raccomandazioni relative all'SSD e il grafico della capacità.
+
La raccomandazione spiega la modifica suggerita e le motivazioni che la supportano. Ad esempio: _Consigliamo di aumentare le dimensioni dell'SSD in base allo schema di utilizzo dell'SSD del file system._

+
Il grafico presenta l'utilizzo attuale degli SSD a confronto con le tendenze storiche e mostra come l'algoritmo di raccomandazione della capacità avrebbe regolato la capacità nel tempo.

. In alto a destra del grafico, selezionare l'intervallo di tempo per modificare il periodo visualizzato. L'impostazione predefinita è una settimana.




=== Eventi ONTAP

Visualizza il numero di eventi EMS rilevati nei file system inclusi, suddivisi per Capacità, Disponibilità e protezione, e Sicurezza e altro.

.Capacità
Visualizza il numero di messaggi EMS relativi a problemi di capacità, insieme al numero di file system interessati.

Esempi di eventi EMS monitorati includono:

* Aggregato quasi pieno/pieno
* Volume quasi pieno/pieno
* riserva di Snapshot quasi piena/piena
* Dimensione directory piena
* FlexGroup pieno
* Inodes pieni


Per un elenco completo degli eventi EMS monitorati, vedere link:https://docs.netapp.com/us-en/ontap-cli-9171/index.html["Eventi di capacità"^].

Selezionando *Capacità* si accede alla schermata di analisi della capacità in Storage workloads.

.Disponibilità e protezione
Visualizza il numero di messaggi EMS relativi alla disponibilità e alla protezione dei dati, insieme al numero di file system interessati.

Gli eventi monitorati includono eventi EMS correlati a FlexCache e SnapMirror.

Selezionando *Availability & protection* si accede alla schermata di analisi della disponibilità e della protezione nei carichi di lavoro di archiviazione.

.Sicurezza e altro
Visualizza il numero di messaggi EMS per eventi non classificati in Capacità o Disponibilità e protezione, insieme al numero di file system interessati. Gli eventi monitorati includono la protezione anti-ransomware, errori di autenticazione NFS e altri.

Selezionando *Security & other* si accede alla schermata di analisi degli eventi nei carichi di lavoro di archiviazione.



== Tabella dei cluster

Fornisce una visualizzazione dettagliata di ogni file system FSx for ONTAP associato alle credenziali AWS configurate, filtrata in base alla regione attiva e alle selezioni dell'account AWS. I dati vengono raccolti dalle metriche di CloudWatch. La tabella supporta la ricerca, il filtro delle colonne, la paginazione, la personalizzazione delle colonne e l'esportazione in formato CSV.

Metriche chiave includono:

* Nome, regione e account AWS
* Metriche della capacità SSD (utilizzata, totale e percentuale di utilizzo)
* Storage del pool di capacità
* Metriche di throughput (media, P95, P99 e massimo negli ultimi 30 giorni)


Utilizza *Utilizzo SSD* per identificare i file system che si stanno avvicinando ai limiti di capacità. Utilizza *Utilizzo throughput (P99)* per confrontare la richiesta di throughput con il throughput SKU fornito. Passa il mouse sopra le intestazioni delle colonne del throughput per visualizzare i dettagli del calcolo.



=== Cerca e filtra

* Utilizzare la ricerca per cercare cluster specifici in base al nome, all'ID del file system, alla regione o ad altri attributi.
* Seleziona qualsiasi intestazione di colonna per ordinare la tabella in base a quella colonna.
* Utilizzare i controlli filtro per colonna per restringere i risultati all'interno della tabella.
* La tabella è suddivisa in pagine. Utilizza i controlli di paginazione in fondo alla tabella per navigare tra le pagine.



NOTE: I file system con raccomandazioni di capacità attive vengono visualizzati con un indicatore a forma di lampadina nella tabella. Seleziona il nome di un file system qualsiasi per visualizzare le metriche di capacità SSD, le tendenze di utilizzo storiche e le raccomandazioni di capacità per quel file system.



=== Personalizza colonne

Per aggiungere o rimuovere colonne dalla tabella dei cluster:

. Seleziona l'icona di selezione delle colonne sopra la tabella a destra.
. Seleziona o deseleziona le colonne che vuoi mostrare o nascondere.
. Selezionare *Applica*.




=== Esporta tabella in CSV

È possibile esportare i dati della tabella attualmente visualizzati in un file CSV per ulteriori analisi o reportistica.

. Applica tutti i filtri o le personalizzazioni delle colonne che desideri riflettere nell'esportazione.
. Selezionare il pulsante image:button_download.png["Scarica"] sopra la tabella dei cluster.


Il file CSV viene scaricato e contiene tutte le righe attualmente visibili nella tabella, incluse solo le colonne attualmente mostrate.
