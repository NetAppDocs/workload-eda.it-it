= Utilizzare la dashboard Panoramica in Workload Factory per EDA
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Utilizza la dashboard Panoramica per monitorare lo stato di salute e la capacità del cluster sui tuoi file system FSx for ONTAP. Filtra i dati, visualizza le raccomandazioni sulla capacità, gestisci le impostazioni di capacità SSD e analizza le tendenze delle prestazioni per prendere decisioni informate sul posizionamento dei volumi e sulla scalabilità della capacità.



== Prima di iniziare

È necessario avere link:task-activate-overview-dashboard.html["ha attivato la dashboard Overview"] prima di poterlo utilizzare per monitorare i file system.



== Filtra la dashboard

Utilizza i filtri nella parte superiore del dashboard per concentrarti su specifici file system. Questi filtri si applicano alle sezioni relative a latenza, utilizzo ed eventi ONTAP, nonché alla tabella dei cluster.

.Passi
. Accedi utilizzando uno dei link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["esperienze di console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger"] e poi seleziona *EDA*.
. Seleziona la scheda *Overview*.
. Utilizza i filtri disponibili per restringere la visualizzazione:
+
** *Account AWS*: Filtra in base a uno o più account AWS associati alle credenziali configurate
** *Credenziali*: Filtra per credenziali AWS specifiche se ne hai configurate più di una
** *Regioni*: Filtra per una o più regioni AWS


. Quando aggiorni le selezioni del filtro, tutte le informazioni vengono aggiornate per mostrare solo i file system corrispondenti.




== Visualizza lo stato di salute del cluster

Nella parte superiore del pannello di controllo viene visualizzata una panoramica dello stato di salute e dell'attività dei file system filtrati. Queste informazioni vengono mostrate solo se almeno un collegamento FSx for ONTAP è associato ai file system.

.Informazioni su questa attività
Lo stato di salute del cluster comprende le seguenti aree chiave:

* *Latenza*: Numero di eventi di latenza rilevati
* *Modalità capacità SSD*: Stato di utilizzo SSD e file system con raccomandazioni sulla capacità attiva
* *Eventi ONTAP*: Numero di eventi EMS per categoria (Capacità, Disponibilità e protezione, Sicurezza e altro)


.Passi
. Esamina lo stato di salute del cluster nella parte superiore della dashboard.
. Per visualizzare gli eventi di latenza:
+
** Seleziona *Rivedi* per accedere alla scheda *Latenza*
** Se il monitoraggio della latenza non è configurato, selezionare *Configura* per impostare le soglie di latenza
+
Per dettagli sul monitoraggio della latenza, vedere link:task-configure-latency-monitoring.html["Configura il monitoraggio della latenza"^].



. Per visualizzare gli eventi ONTAP per i file system FSx for ONTAP, selezionare *Rivedi*.
+
La scheda di visualizzazione degli eventi ONTAP mostra il numero di eventi EMS per categoria (Capacità, Disponibilità e protezione e Sicurezza e altro). Per un elenco completo degli eventi EMS monitorati, vedere link:https://docs.netapp.com/us-en/ontap-cli-9171/index.html["Documentazione CLI ONTAP"^].





== Visualizza e applica le raccomandazioni sulla capacità

Workload Factory esegue automaticamente un algoritmo di raccomandazione della capacità per ogni file system FSx for ONTAP. È possibile identificare i file system con raccomandazioni di capacità filtrando la tabella Cluster.

.Passi
. Nella tabella *Cluster*, filtra in base alle colonne *Timestamp ultimo aumento SSD* o *Descrizione ultimo aumento SSD*.
+
I file system con raccomandazioni di capacità vengono visualizzati nella parte superiore della tabella.

. Seleziona un nome di file system nella tabella per aprirlo e visualizzare i suggerimenti.
. Esaminate le raccomandazioni relative all'SSD e il grafico della capacità.
+
La raccomandazione spiega la modifica suggerita e le motivazioni che la supportano. Ad esempio: _Consigliamo di aumentare le dimensioni dell'SSD in base allo schema di utilizzo dell'SSD del file system._

+
Il grafico presenta l'utilizzo attuale degli SSD a confronto con le tendenze storiche e mostra come l'algoritmo di raccomandazione della capacità avrebbe regolato la capacità nel tempo.

. In alto a destra del grafico, selezionare l'intervallo di tempo per modificare il periodo visualizzato. L'impostazione predefinita è una settimana.
+
Il grafico visualizza anche i punti decisionali relativi alle raccomandazioni e i punti decisionali relativi all'automazione (se la modalità di automazione è abilitata). Passando il mouse su un punto decisionale qualsiasi, è possibile visualizzare i dettagli relativi alla raccomandazione di capacità o all'azione di automazione in quel momento.

. Per applicare la raccomandazione, segui le istruzioni fornite nel messaggio di raccomandazione.




== Modifica la modalità di gestione dell'SSD

Modifica la modalità di gestione della capacità SSD per i singoli file system per controllare se desideri raccomandazioni manuali o scalabilità della capacità automatizzata.

.Informazioni su questa attività
Le modalità di gestione dell'SSD includono:

* *Automatizza*: Aumenta automaticamente la capacità SSD in base a soglie predefinite
* *Consigliato*: Ricevi raccomandazioni sulla capacità che puoi esaminare e applicare manualmente
* *Nessuno*: Nessuna raccomandazione di capacità o azioni automatizzate


Selezionando la modalità Automatizza, è possibile configurare i parametri Soglia, Analisi retrospettiva e Previsione che controllano il modo in cui il sistema di gestione della capacità analizza l'utilizzo dell'SSD e prende decisioni automatizzate. Selezionando la modalità Raccomanda, è possibile configurare solo il parametro Soglia.

* *Soglia* (10-90%): la percentuale di utilizzo dell'SSD che attiva i suggerimenti di capacità o le azioni automatizzate
* *Retrospettiva* (1-200 ore): il periodo di tempo utilizzato per analizzare i modelli storici di utilizzo degli SSD
* *In anticipo* (1-200 ore): il periodo di tempo utilizzato per prevedere il fabbisogno di capacità futuro


.Passi
. Nella tabella Cluster, individua il nome del file system. Accanto ad esso, apri image:icon-action.png["l'icona del menu delle azioni"] e seleziona *Modifica gestione della capacità SSD*.
. Scegli la modalità che preferisci:
+
** *Nessuno*: Disabilita gestione della capacità
** *Consigliato*: Imposta il parametro Threshold per l'analisi delle raccomandazioni
** *Automatizza*: Imposta i parametri di soglia, di analisi retrospettiva e di previsione per la scalabilità della capacità


. Selezionare *Applica*.


.Risultato
Il file system utilizza immediatamente la nuova modalità. Se hai selezionato Consiglia o Automatizza, il sistema utilizza i parametri configurati per l'analisi della capacità e il processo decisionale.



== Modifica in blocco i parametri di gestione SSD

Regola i parametri di gestione della capacità SSD per più file system contemporaneamente, in modo da applicare impostazioni coerenti a tutti i cluster.

.Informazioni su questa attività
Quando si selezionano più file system per la modifica in blocco:

* Se tutti i file system selezionati hanno valori di parametro identici, tali valori vengono visualizzati come predefiniti nella finestra di dialogo di modifica
* Se uno qualsiasi dei file system selezionati è in modalità None, nella finestra di dialogo vengono visualizzati i valori predefiniti
* Se i valori dei parametri differiscono tra i file system selezionati, nella finestra di dialogo vengono inseriti i valori predefiniti


.Passi
. Dalla scheda *Panoramica*, seleziona i file system che desideri modificare nella tabella.
+

TIP: È possibile selezionare singoli file system oppure utilizzare la casella di controllo nell'intestazione per selezionare tutti i file system visibili.

. Seleziona *Modifica gestione della capacità* sopra la tabella.
. Scegli la modalità che preferisci.
. Nella finestra di dialogo di modifica, regolare i parametri Threshold, Lookback e Ahead secondo necessità.
+
Ciascun campo parametro include una descrizione che ne illustra lo scopo e l'intervallo di validità. La finestra di dialogo indica i valori correnti o predefiniti in base alla selezione effettuata.

. Seleziona *Applica* per applicare le modifiche a tutti i file system selezionati.


.Risultato
I parametri vengono aggiornati per tutti i file system selezionati. I file system in modalità Recommend o Automate utilizzano immediatamente i nuovi parametri per l'analisi della capacità e il processo decisionale.



== Analizzare le tendenze di capacità e i punti decisionali

Utilizza il grafico di utilizzo degli SSD per comprendere l'andamento della capacità nel tempo e identificare modelli nella gestione della capacità.

.Informazioni su questa attività
I punti decisionali sul grafico indicano quando:

* *Punti decisionali di raccomandazione*: L'algoritmo di raccomandazione della capacità ha rilevato la necessità di ulteriore capacità SSD. Questi possono verificarsi con una frequenza fino a ogni 30 minuti se la capacità SSD non è stata aumentata.
* *Punti decisionali dell'automazione*: Il sistema di automazione ha tentato di aumentare la capacità SSD. Questi punti indicano se l'azione è riuscita o meno.


.Passi
. Nella scheda *Panoramica*, selezionare il nome di un file system nella tabella.
. Esamina il grafico di utilizzo dell'SSD che mostra l'andamento storico della capacità.
. Seleziona intervalli di tempo diversi per visualizzare l'andamento della capacità in vari periodi.
. Passa il mouse sui punti decisionali del grafico per visualizzare i dettagli relativi ai consigli o alle azioni di automazione in momenti specifici.
. Utilizza le informazioni ricavate dal grafico per:
+
** Comprendere con quale frequenza sono necessari gli aggiustamenti di capacità
** Valuta se la modalità di automazione o quella di raccomandazione si adatta meglio ai tuoi modelli di carico di lavoro
** Identificare i vincoli di capacità ricorrenti
** Pianificare le future esigenze di capacità in base alle tendenze di crescita
** Risoluzione dei problemi relativi ai tentativi di automazione non riusciti






== Utilizzare la tabella dei cluster

La tabella dei cluster fornisce una visualizzazione dettagliata di ciascun file system FSx for ONTAP con metriche sulle prestazioni e sull'utilizzo.

.Passi
. Dalla scheda *Panoramica*, consultare la tabella dei cluster.
. Utilizza la casella di ricerca per trovare file system specifici in base al nome.
. Seleziona le intestazioni di colonna per ordinare i dati.
. Utilizza *Utilizzo SSD* per identificare i file system che si stanno avvicinando ai limiti di capacità.
. Utilizza *Utilizzo throughput (P99)* per confrontare la richiesta di throughput con il throughput SKU fornito.
+
Passa il mouse sopra le intestazioni delle colonne del throughput per visualizzare i dettagli del calcolo.

. Per personalizzare le colonne, seleziona l'icona delle impostazioni delle colonne e scegli quali colonne visualizzare.
. Per esportare i dati, seleziona l'icona di esportazione per scaricare un file CSV.
. Per eseguire operazioni in blocco, selezionare più file system utilizzando le caselle di controllo, quindi selezionare *Modifica parametri*.




== Best practice

Prendere in considerazione queste raccomandazioni quando si utilizza la dashboard Panoramica:

* *Monitoraggio regolare*: Controlla regolarmente la dashboard per identificare le tendenze prima che diventino problemi.
* *Imposta soglie appropriate*: configura le soglie di gestione degli SSD in base ai tuoi modelli di carico di lavoro e alle preferenze di pianificazione della capacità.
* *Utilizza i filtri in modo efficace*: combina i filtri per regione e per account per concentrarti su specifici sottoinsiemi della tua infrastruttura.
* *Esaminare tempestivamente i suggerimenti*: filtrare la tabella Cluster in base alla data e all'ora dell'ultimo aumento SSD o alla descrizione per identificare i file system con raccomandazioni di capacità. Esaminare e seguire queste raccomandazioni per evitare limitazioni di capacità.
* *Scegli la modalità corretta*: usa la modalità Consiglia quando vuoi avere il controllo sulle decisioni relative alla capacità, oppure la modalità Automazione per una gestione completamente automatizzata.
* *Monitorare i punti decisionali*: Esaminare regolarmente i punti decisionali sui grafici di capacità per comprendere il comportamento dell'algoritmo e verificare che le impostazioni corrispondano alle proprie esigenze.
* *Sfrutta la modifica in blocco*: Quando gestisci più file system, utilizza la modifica in blocco dei parametri per mantenere politiche di gestione della capacità coerenti.
